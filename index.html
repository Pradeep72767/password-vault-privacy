Privacy Policy

Password Vault

Effective Date: November 11, 2026

1. Introduction

Password Vault is a personal password management application designed to help users securely store, organize, and manage credentials for multiple websites, applications, and online platforms.

The application follows a local-first approach. User vault information is stored on the user's Android device rather than in a cloud-based password database.

2. Information We Handle

When creating a vault, users provide:

  • Name
  • Email address
  • Vault Password (Master Password)

Users can also save account information such as:

  • Platform or website name
  • Account category
  • Platform username or email
  • Platform password

This information is entered voluntarily by users for password management purposes.

3. Local Data Storage

Password Vault uses a local Room Database to store vault registration information and saved account records on the user's Android device.

  • Information is stored locally.
  • Saved account credentials are encrypted before database storage.
  • The application does not maintain a remote database of saved passwords.
  • The application does not provide cloud synchronization.
  • Saved credentials are not transmitted to our servers.

4. Password Encryption and Security

Password Vault uses AES-256-GCM encryption as part of its data protection mechanism.

Saved account credentials are encrypted before being stored in the local database. When a user wants to view a saved password, the application requests the Vault Password and verifies it before allowing access to the decrypted credential.

Encrypted credentials are displayed in the password list rather than their original plaintext values.

We take reasonable technical measures to protect user information. However, no electronic storage or security mechanism can guarantee absolute protection.

5. Vault Password

The Vault Password protects access to the user's password vault. Users are responsible for keeping this password confidential.

If the Vault Password is forgotten, recovery may not be possible, depending on the application's recovery functionality.

6. Backup and Restore

Password Vault provides an optional backup and restore feature. Users can export saved account information into a password-protected JSON backup file.

Backup:

  • The backup file is protected using a backup password.
  • Users can save the exported file to a location of their choice.

Restore:

  • Users must enter the correct backup password.
  • The application verifies the backup protection before importing.
  • After successful verification, account records are restored to the local database.

Users are responsible for keeping backup files and backup passwords secure. Backup files saved to third-party storage providers are also subject to those providers' privacy policies.

7. Data Sharing and Third-Party Services

Password Vault does not sell, rent, or share saved account credentials with third parties.

Based on the current application implementation, the app does not use Firebase, Google Analytics, AdMob, or third-party cloud storage services.

Saved credentials are not transmitted to our servers.

8. Data Retention and Deletion

User information remains stored locally until it is deleted through the application's available functionality or the application data is removed.

Uninstalling the application or clearing its data may permanently remove locally stored information.

Exported backup files are stored separately and may need to be deleted manually from the location where they were saved.

9. Device Security

Users should protect their devices with a screen lock, keep their operating systems updated, and avoid sharing their Vault Password or backup password.

10. Children's Privacy

Password Vault is a general-purpose password management application and is not specifically designed for children.

11. Changes to This Privacy Policy

We may update this Privacy Policy when application features, security practices, or applicable requirements change. Updated versions will be published on this page with a revised effective date.
